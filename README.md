# TaskFlow - Low-Fidelity Wireframes

## Project Overview
TaskFlow is a low-fidelity mobile task management application designed for students to organize daily tasks, assignments, reminders, and schedules efficiently.

This project was created as part of an internship task to understand early-stage UI/UX planning, user flow creation, and mobile app wireframing.

---

## Objective
- Understand mobile app wireframing
- Learn user flow creation
- Practice low-fidelity UI/UX design
- Create mobile app layouts using Figma
- Understand design thinking process

---

## Features
The application includes the following wireframe screens:

1. Splash Screen
2. Login Screen
3. Home Screen
4. Add Task Screen
5. Task Details Screen

---

## Wireframe Screens

### Splash Screen
- App logo
- App name
- Loading indicator

### Login Screen
- Email input
- Password input
- Login button
- Google sign in option

### Home Screen
- Task list
- Priority indicators
- Navigation menu

### Add Task Screen
- Add task form
- Due date and time
- Priority selection
- Notes section

### Task Details Screen
- Full task information
- Edit task option
- Delete task option
